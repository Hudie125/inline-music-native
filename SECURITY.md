# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within inline Music, please do not file a public issue. Instead, report it privately to the maintainers at `kronyxxbezdar@gmail.com`.

We commit to acknowledging your report within 48 hours and providing a clear timeline for remediation.
